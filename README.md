# Kırıkkale Korsan Taksi

Kırıkkale korsan taksi hattı Ankara'ya bağlı çalışır. Esenboğa Havalimanı Kırıkkale merkezden 92 kilometre, 1 saat 9 dakika uzaklıktadır; Yahşihan'dan çıkan için 88 kilometredir. Başkentteki hastane ve resmi daire işleri de aynı yoldan yapılır.

Makine ve kimya fabrikalarının vardiyaları ile rafineri personeli şehir içi düzenli yolcudur. Ankara'da randevusu olan hasta ve refakatçi kapıdan alınır, muayene bitince geri getirilir. Çelebi 143, Delice 141 kilometreyle uzak ilçelerdir.
